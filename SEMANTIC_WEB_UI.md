# Verhöfisch Gesagt – Semantic Engine v2 Offline

Die HTML-Datei enthält die Semantic Engine v2 direkt eingebettet.

- kein Node.js erforderlich
- kein Webserver erforderlich
- keine API erforderlich
- keine Internetverbindung erforderlich
- funktioniert direkt als `file://`-Datei

Die klassische Engine bleibt als Fallback vollständig erhalten. Die Semantic Engine nutzt Tokenisierung, Morphologie, Syntaxanalyse, Semantic IR und stilabhängige Realisierung direkt im Browser.
